# Netflix India
## 🚀 Tech Stack
- **Frontend**: React.js
- **CSS**: Tailwind CSS

## 📦 Setup
1. Clone the repo: `git clone https://github.com/NssGourav/Netflix-for-india.git`
2. Install dependencies: `npm install`
3. Set up Firebase by adding your config in `.env` file.
4. Run locally: `npm start`

## 🚀 Deployment
- Deploy using Firebase Hosting.
